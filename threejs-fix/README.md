# Ann Studios — Three.js Edition

A self-contained redesign of the Ann Studios website. Open `index.html` through a local web server; the Three.js runtime and all game artwork are included in this folder.

## Local preview

```powershell
node server.mjs
```

The five supplied concepts—Bear Baker, Chicken Mafia, Duck Racer, Hamster Hacker and Pigeon Empire—appear as coming-soon games.
