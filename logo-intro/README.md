# Ann Studios animated logo intro

A standalone red-and-white studio ident built with HTML, CSS, SVG, and a small amount of JavaScript. The game controller and camera form the brand mark, trigger a shutter flash, and resolve into the supplied Ann Studios logo.

## Preview

From this folder, run:

```powershell
npx serve . -l 4175
```

Then open `http://localhost:4175`.

- Use **Replay**, `R`, or the Space bar to restart the sequence.
- Open `http://localhost:4175/?loop=1` for continuous playback.
- Reduced-motion preferences automatically skip to the final logo.

The intro is self-contained and can be placed before a game menu or packaged into a web-based game build.
